## Who runs this site

Steven B. Combs, Ph.D. publishes this site as retroCombs at [retrocombs.com]({{ "/" | relative_url }}).

## The YouTube API app

Steven uses a private app, in the Google Cloud project `youtube-and-companion`, with the YouTube Data API and the YouTube Analytics API. It reads data only from his own YouTube channels, retroCombs and retroCombs Tech, for his own analytics and channel management.

The app does not access, collect, or store any visitor's or other user's Google or YouTube data. It does not sell or share data.

The app uses YouTube API Services. Those services are covered by the [YouTube Terms of Service](https://www.youtube.com/t/terms) and the [Google Privacy Policy](https://policies.google.com/privacy). Access granted to the app can be revoked in [Google security settings](https://security.google.com/settings/security/permissions).

## What this website uses

This is what the site actually loads. It does not load Google Fonts. Typefaces (Inter, JetBrains Mono, Press Start 2P, and VT323) are files hosted with the site.

**Google Analytics.** Every page loads Google Analytics 4, measurement ID `G-GMC3C0FD4Z`, through [gtag.js](https://www.googletagmanager.com/gtag/js?id=G-GMC3C0FD4Z). Google uses cookies, including cookies named `_ga`, to recognize a browser and count visits. See the [Google Privacy Policy](https://policies.google.com/privacy).

**Google AdSense.** On pages that do not turn ads off, the site loads the AdSense script `adsbygoogle.js` for publisher `ca-pub-4132959196132899`. Posts place units in the article, after the article, and in the desktop sidebar. The homepage places one unit between the blog rows. Topic pages place one unit after the page. Those units can set advertising cookies. This page turns ads off and does not load the script. See the [Google Privacy Policy](https://policies.google.com/privacy) and [How Google uses information from sites or apps that use our services](https://policies.google.com/technologies/partner-sites).

**Comments.** Posts load [giscus](https://giscus.app) from `giscus.app`. If you comment, you sign in with GitHub, and the comment is stored in GitHub Discussions on the `stevencombs/retrocombs.github.io` repository under the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).

**YouTube videos.** The site's video player asks YouTube for a thumbnail image from `i.ytimg.com` when the page loads. The player itself comes from `youtube-nocookie.com` and loads only after you press play. See the [Google Privacy Policy](https://policies.google.com/privacy). A few older posts also embed a Vimeo video, Flickr galleries, Google Slides, or an Amazon banner. Those load only on the posts that include them: [Vimeo](https://vimeo.com/privacy), [Flickr](https://www.flickr.com/help/privacy), [Google](https://policies.google.com/privacy), and [Amazon](https://www.amazon.com/privacy).

**Search.** Search runs in your browser. It downloads this site's own index at `/search.json`. It does not send your query to a third party, and it does not set a cookie.

**Hosting.** [GitHub Pages](https://pages.github.com/) serves the site. GitHub may keep ordinary server logs, such as an IP address and the page requested. See the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement).
