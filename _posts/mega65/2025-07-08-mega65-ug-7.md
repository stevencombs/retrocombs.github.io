## GETTING FILES TO THE MEGA65

While writing your own programs on the MEGA65 is rewarding, you'll eventually want to run software created by others or back up your work. File transfers are the key, and the MEGA65 offers several options:

1. **Ethernet**: The fastest and most reliable method for transferring files, using an Ethernet cable. It supports both direct and network connections, and the MEGA65 team has created both GUI and terminal software to make the transfer easy. We'll look at both in this chapter.
2. **SD card transfer**: Something you are probably all familiar with. Copy files or `.D81` images directly onto an SD card using your PC. Remember to format the SD card using the MEGA65; see [Chapter 4](/mega65-ug-4) for that process. This is the most unreliable and cumbersome method. I call it unreliable because PC operating systems (I'm talking to you, macOS!) can write unintended files to SD cards, causing clutter and confusion, and other operating systems can fragment files, leading to errors. This used to be the only way to move files, but thanks to the developers, that's no longer the case.
3. **Advanced developer interfaces**: Such as JTAG and UART. You can use these to transfer files and debug FPGA cores. This method is beyond the scope of this series, but you can find more information in the [MEGA65 Developer's Guide](https://files.mega65.org?id=ffd575e5-5d9c-47ff-b553-fcec80fd77a3). If you are interested in a serial connection using a UART adapter, check out my [Connect a MEGA65 to a Mac/PC using a USB Serial Adapter](https://youtu.be/jJs8PmaZ1VY) video.

All three methods are valid; however, Ethernet is the recommended method for most users because of its speed and reliability. Let's learn more about the tools that help you transfer files over an Ethernet cable. But first, we need to understand networking.

## UNDERSTANDING NETWORKING

The MEGA65 comes with Ethernet capabilities, allowing it to connect to your local network or directly to your PC. Let's break down how this works:

- **MAC address**: Unlike most devices, the MEGA65 lets you set your own Media Access Control (MAC) address in the Configuration Utility. This gives you a unique identifier on your network. We covered this in [Chapter 4](/mega65-ug-4).
- **Two connection options**: Connect your MEGA65 to your local network through a router like any other device, or connect it directly to your PC with an Ethernet cable. A direct connection creates a small, isolated network between the two devices.
- **IPv6**: For file transfers, the MEGA65 uses IPv6, the newer internet protocol that's typically enabled by default on most modern PCs. IPv6 is a 128-bit address upgrade to IPv4, designed to provide more addresses to the world. IPv6 is required for M65Connect and the other tools to work. It's nice to know the MEGA65 developers are looking forward, not to the past, when it comes to network connectivity!
- **UDP**: MEGA65 networking tools use the User Datagram Protocol (UDP) at port 4510 for the initial connection, and the file transfer then happens over IPv6. Together, this provides a reliable connection and file transfer.

> **TIP:** Your PC might ask for network permissions the first time you use these tools. Be sure to allow or approve them.

While this chapter focuses on local network transfers, it's worth mentioning that the MEGA65 can also connect to the internet and to BBSes via Telnet using software called PETterm, available on the [Filehost](https://files.mega65.org). It runs in C64 mode but uses some MEGA65 features to make the magic happen. Be warned: it is still a work in progress. Here's hoping some enterprising developers grab that software, work out the bugs, and connect us to a whole world of internet BBSes from our MEGA65s!

## OBTAINING M65CONNECT

Our focus today is using the MEGA65 on a local network, and one of the best ways to do that is with an application called **M65Connect**. It features both a graphical interface and command line tools. I've teased this application in other chapters, and now it's time to download and install it:

1. Visit the [MEGA65 Filehost](https://files.mega65.org).
2. Search for *M65Connect*.
3. Download the version that matches your PC's operating system. I'm using a Mac for all my examples.
4. Extract the downloaded archive.

Here's the process on three popular modern operating systems.

### Windows

When you decompress the archive for M65Connect for Windows, you'll find a folder called *M65Connect*. Click the `M65Connect.exe` file to start the application. If Microsoft Defender blocks it, click **More info** and then **Run anyway**, and the application should start.

### macOS

The macOS version is an app bundle named `M65Connect.app`. To run it:

1. Move the app to your *Applications* folder.
2. Double-click the app to launch it.
3. Since the application is not signed, approve the first launch in the Mac's security settings.

### Linux

Double-click the *M65Connect* file in the extracted folder to run the application. Linux is by far the most trouble-free install and the quickest way to run M65Connect.

## ENABLE NETWORK LISTENING

Before transferring files, you must enable network listening on the MEGA65, and the first time requires a small hardware change: set **DIP switch #2** on the main board to **ON**. It is off by default, so if this is your first time trying this feature, you'll need to open your MEGA65. It's okay to do this, and the process is very easy. Remove the screws from the bottom and lift the lid to reveal the motherboard. I keep my screws out all the time because I'm constantly experimenting with my MEGA65. You probably don't need to, so you might want to replace the screws once you get that DIP switch flipped.

With the DIP switch set:

1. Press `SHIFT` + `£` (the pound key) on the MEGA65.
2. The power light will blink yellow and green. That indicates network listening is now active.
3. To disable it, press `SHIFT` + `£` again, or reset or power cycle the MEGA65.

Your MEGA65 is now ready to transfer files across your network or from your PC.

## TRANSFERRING FILES WITH M65CONNECT

File transfer requires initiating a session on your PC and the MEGA65 using either M65Connect or command line tools such as `mega65_ftp`.

> **WARNING:** Save any data or programs before you initiate a file transfer. The MEGA65 resets the machine to start the transfer.

Let's start with the easiest tool to use, M65Connect:

1. Open M65Connect on your PC.
2. Press `SHIFT` + `£` to enable network listening on the MEGA65.
3. Once connected, click the **SD Card** button in M65Connect to open the file manager.
4. Use the left pane to navigate your PC's files and the right pane for the MEGA65 SD card.
5. Select a file and click the transfer arrow to copy it.

A connection also gives you these additional features:

- **Create a new `.D81` image** by clicking the **+D81** button.
- **Transfer files directly to and from a `.D81` image on the PC**, which is really cool. Click the `.D81` file and drag a `.PRG` or other file onto it from your PC. Once the file is in the `.D81`, you can transfer it to the MEGA65.

When you're done, close the SD Card Manager to end your session and restart your MEGA65.

> **NOTE:** A network connection does not allow some M65Connect features, such as screen capture, to work. I really miss that one! You'll need a serial connection for screen capture, so check out my [USB serial adapter video](https://youtu.be/jJs8PmaZ1VY) if you need it. Hopefully that feature will come to network connections in a future version of M65Connect.

## TRANSFERRING FILES WITH MEGA65_FTP

Let's warm up those fingers! The `mega65_ftp` tool offers advanced users a command line interface for network transfers with some really cool options. It's included with the MEGA65 tools alongside M65Connect. My examples use the macOS build (`mega65_ftp.osx`) from a terminal opened in my `m65tools` folder.

### Interactive Mode

To start an interactive session:

1. Save any data on your MEGA65.
2. Press `SHIFT` + `£` to enable network listening on your MEGA65.
3. From the terminal on your PC, start the interactive connection. The `-e` option connects over Ethernet:

```bash
./mega65_ftp.osx -e
```

Once connected, you'll see a note that the SD card was detected, followed by the prompt:

```
Type 'help' to get a list of commands available.
MEGA65 SD-Card:/>
```

Here are some of the commands available at the `mega65_ftp` prompt:

| Command | Action |
|---|---|
| `get <file>` | Retrieve a file from the MEGA65 |
| `put <file>` | Send a file to the MEGA65 |
| `dir` | List the directory of the MEGA65 SD card |
| `ldir` | List the local working directory on your PC |
| `mkdir <folder>` | Create a subdirectory on the MEGA65 SD card |
| `cd <folder>` | Move to a subdirectory on the MEGA65 SD card |
| `lcd <folder>` | Move to a local subdirectory on your PC |
| `help` | List all available commands |
| `exit` | Close the `mega65_ftp` connection |

Here's a short session like the one in the video. It downloads a file, sends it back, creates a folder on the SD card, and moves into it:

```
MEGA65 SD-Card:/> get README.md
MEGA65 SD-Card:/> put README.md
MEGA65 SD-Card:/> mkdir test-dir
MEGA65 SD-Card:/> cd test-dir
MEGA65 SD-Card:/test-dir> dir
MEGA65 SD-Card:/test-dir> exit
```

When you `exit`, `mega65_ftp` resets the MEGA65 and returns you to your terminal.

### Non-Interactive Mode

Interactive mode will suffice for most transfers. However, you can also run commands non-interactively, as part of a script, or just out of preference for one-off commands and speed. Non-interactive mode is also great for creating alias commands to decrease typing and speed up transfers. Here's the example from the video:

```bash
./mega65_ftp.osx -e -c 'put wow1.d64' -c 'exit'
```

## MORE COMMAND LINE TOOLS

Although it's not covered in the MEGA65 User's Guide, `mega65_ftp` is not the only command line tool you should explore. When you install the MEGA65 tools, you'll also have access to a few more commands:

- **`etherload`**: Additional network tools for developers that can also be useful for users. Check the help (`-h`) to see how you can use this command.
- **`m65`**: Another terminal command with additional tools to manage a MEGA65. If you'd like me to spend more time on this one, leave a comment.
- **`romdiff`**: Of use for those who haven't purchased a MEGA65 yet. This lets you patch the contents of the original C65 ROM with the additions from the MEGA65 developers and create a ROM you can use in emulation or even on an FPGA board. As a reminder, the original C65 ROM is protected by copyright, so this tool is for those who have access to the original C65 ROM and want to move it forward. I show you how in my [Patch a Commodore 65 ROM video](https://youtu.be/volGqBd143k).
