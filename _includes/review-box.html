{%- comment -%} retroCombs review box. Default layout is the horizontal row. type: rewind (default), first-look, bench, compared, or take. Omitted or unknown types render REWIND, so the live scored boxes stay put. Only rewind renders the score strip and Product/Review JSON-LD. REWIND score: 0.5, 1, 1.5, 2, 2.5, 3, 3.5, 4, 4.5, or 5. A half score highlights the whole number below. 0.5 highlights GAME OVER. When score is omitted, rating is used, then page.rating. The band name comes from _includes/rating-band.html. price: optional. Amount only, plain text, no link. Example: $278.50 When price is omitted, the price line is not rendered. where: store and date, plain text, no link. Example: at ClonerAlliance (as of Oct 28, 2026) Shown on the price line only when price is set. summary: one or two sentences. note: optional sentence under the box. product: optional product name. When set, a Product/Review JSON-LD block is added (author Steven B. Combs, or the rater when set; ratingValue from score, bestRating 5). channel: optional. "tech" or "retrocombs". Draws the header-row badge via review-channel.html (variant row, the default). rater: optional guest rater full name, e.g. "The Lovely Accountant". Draws "Rated by " under the joystick strip / rating name, above the price, and makes the JSON-LD review author the rater. Not set = nothing renders and the rating is Steven's (author Steven B. Combs). rater_short: optional short form, e.g. "TLA". Used only as a phone chip (under 760px) when the full name is longer than 24 characters, or when rater_mobile="short". The chip carries the full name in title and aria-label. rater_mobile: optional "full" or "short" to override that phone choice. "full" keeps the full "Rated by …" line on phones. FIRST LOOK (no score) summary, optional price and where, optional full_review (internal path). Always shows a NOT YET RATED chip. full_review renders "Full review →". BENCH (no score) summary. Optional difficulty, time, cost, and status. Each one is hidden when absent. Optional parts line (plain text, no link). COMPARED (no score) summary, optional price and where, and up to three items: pick1_name, pick1_text, pick1_badge (for example "MY PICK"), pick1_role. pick2_ and pick3_ use the same fields. pickN_role="runner-up" names that item as the runner-up and does not draw a chip. A row is skipped when its name is empty. TAKE (no score) summary, optional price and where, optional chip (for example "RECOMMENDED"). The chip is hidden when chip is empty. No score. example: "true" stamps the box EXAMPLE. For the component preview only. Price-line format is provisional. When price is set, this is the only markup for it: Price:pricewhere The whole price paragraph is omitted when price is empty. Bench uses cost in the facts row, not this price line. Pointer icon is provisional (the logo joystick). Change rc_ptr and rc_ptr2 here to swap it.
